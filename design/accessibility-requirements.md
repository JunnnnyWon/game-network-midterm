# Accessibility Requirements

- Tier: Standard
- Date: 2026-04-16

## Visual
- High-contrast score/timer/readiness states
- Clear debuff/trap indicators with text or icon support
- Do not rely on color alone for critical state

## Motor
- Keyboard/mouse-only MVP with forgiving menu navigation
- Enter/Escape shortcuts for confirm/back
- Minimal simultaneous-input burden in UI flow

## Cognitive
- Clear room-state transitions (Lobby, Countdown, Active, Results)
- Explicit end reasons and persistence status
- Simple cue vocabulary and predictable controls

## Auditory
- Audio is supplementary, not required for rule comprehension
- Critical match/result state must always have visual equivalents
