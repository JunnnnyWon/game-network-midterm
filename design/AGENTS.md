# Design Directory — Codex Rules

Use this scope for design documents and system GDD authoring.

## Rules
- Preserve the original 8-section GDD discipline for system docs:
  Overview, Player Fantasy, Detailed Rules, Formulas, Edge Cases, Dependencies, Tuning Knobs, Acceptance Criteria.
- Update `design/gdd/systems-index.md` when new systems are added.
- Use one-question-at-a-time collaborative flows when eliciting design decisions.
- Prefer explicit formulas, boundaries, and testable acceptance criteria over prose-only design language.
