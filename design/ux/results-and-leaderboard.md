# UX Spec — Results and Leaderboard

- Status: Reviewed
- Purpose: Show final outcome, save state, and persistent ranking.

## Results requirements
- Win/loss/draw text
- Final scores
- Explicit MatchEndReason
- Persistence status: saving / saved / save failed

## Leaderboard requirements
- Rank, Player, Wins, Best Score, Matches
- Refresh action
- Back to lobby path
