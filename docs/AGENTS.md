# Docs Directory — Codex Rules

Use this scope for architecture docs, ADRs, reference docs, and migration notes.

## Rules
- Keep architecture decisions traceable and testable.
- Preserve ADR discipline: Title, Status, Context, Decision, Consequences, Dependencies/Follow-ups.
- Document every required Codex-vs-Claude deviation that affects onboarding or workflow parity.
- README and architecture docs must agree on the active runtime model.
